# Предложения по изменению GDD

GDD (`docs/GDD.md`) не правится без решения владельца. Здесь копятся предложения с аргументами; статус: `открыто` / `принято` / `отклонено`. Принятое вносит в GDD владелец документа.

**15.10.2026:** владелец выпустил `docs/MVP.md` и `docs/ROADMAP-v1-v2.md`: с этого момента они источник истины и при расхождении правы. P-10…P-23 фиксируют решения владельца ([решено] и [GDD] из этих файлов) и уже внесены в GDD. P-24…P-35 — пометки [предложение] из тех же файлов: разумные умолчания, заложенные в данные, но не решения владельца (статус «открыто»). Таблица расхождений: `docs/design-revision-2026-10-15.md`, вопросы: `docs/open-questions.md`.
