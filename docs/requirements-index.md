Источник: `docs/GDD.md` (редакция 2 от 15.10.2026, приведена к `docs/MVP.md` и `docs/ROADMAP-v1-v2.md`, которые — источники истины). Изменения: P-10…P-35 в `docs/gdd-change-proposals.md`. Раскладка по вехам M2–M5 — [предложение, P-30]: таблица вех из MVP.md в текст не попала. Веха указана только для требований с приоритетом MVP (или с MVP-частью). Колонка «Статус» обновляется по ходу реализации: `—` не начато, `wip` в работе, `done` принято.

Правило разнесения по вехам: требование попадает в ту веху, где оно нужно для критерия приёмки (раздел 18 GDD). Если MVP-часть требования растянута на несколько вех, основная веха указана первой, расширения — в примечании.
