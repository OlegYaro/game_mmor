# Индекс требований

Источник: `docs/GDD.md` (версия от 14.10.2026). Веха указана только для требований с приоритетом MVP (или с MVP-частью). Колонка «Статус» обновляется по ходу реализации: `—` не начато, `wip` в работе, `done` принято.

Правило разнесения по вехам: требование попадает в ту веху, где оно нужно для критерия приёмки (раздел 18 GDD). Если MVP-часть требования растянута на несколько вех, основная веха указана первой, расширения — в примечании.
