# Перемещение через карту мира

Дата: 2026-10-15. Исследование #9 из `docs/MVP.md`. Веха: **M5**. Поверхностное; связано с ADR 0003 (длина пути на графе чанков), ADR 0005 (детерминизм), ADR 0013 (`Party`, переход как отряд с целью и временем).

Пометки: **[факт]** — из источника, **[предложение]** — моя прикидка, **[не подтверждено]** — источника нет.

## Краткие выводы

1. Время простое: игровой день = 15 минут = 9000 тиков, час = 375 тиков. Переход — это отряд (`Party`) с целью и тиком прибытия, всё считается в целых тиках. [предложение, по MVP.md]
2. Промотка времени детерминирована, только если время идёт теми же тиками симуляции: любое «перескакивание» без вызова тика ломает реплей и сохранения. Поэтому либо тики идут быстрее (ускорение без отрисовки), либо переход идёт на обычных скоростях ×1/×2/×4 [предложение; следует из ADR 0005].
3. В Battle Brothers путешествие идёт по карте с ускорением времени, по пути возможны встречи: торговцы, наёмники, звери, разбойники, лагеря [S1]. В Kenshi отдельной карты перехода нет: игрок идёт пешком, время ускоряют вручную; по одному из комментариев, путь между поселениями может занимать от 15 минут до часа реального времени [S2, слабый источник]. Для Mount & Blade формулу скорости отряда (размер, местность) подтвердить не удалось [не подтверждено].
4. Длина пути считается на абстрактном графе чанков, не по тайлам (ADR 0003); стоимость тайла (дорога, тропа, лес) входит коэффициентом из `data/balance/`. Карта 2048² на 64×64 чанках даёт граф порядка 4096 узлов: одного запроса достаточно. [оценка]
5. Предложение владельца — переход стоит игрового времени по длине пути. Сама идея стандартная для жанра; детали (скорость, вес отряда) надо задать в данных.
6. Набег на домашнее поселение прерывает переход: решено в MVP. Предупреждение за 3 часа (e1) приходит и во время перехода; значит, игрок узнаёт об угрозе и может вернуться, если ему хватит времени.

## Варианты

| Вопрос | Вариант | Плюсы | Минусы |
| --- | --- | --- | --- |
| Как проматывать | A. Принудительная скорость ×4 до прибытия или прерывания | Ничего нового в Core; реплей — как обычный | Долго: переход на 2 дня при ×4 ≈ 3,75 мин реальных |
| | B. Ускоренный цикл тиков без рендера (до сотен тиков за кадр) | Быстро | Потолок бюджета: в тике все активные чанки; нужен лимит и индикатор |
| | C. Прыжок: стратегический слой считается часовыми шагами (375 тиков), активные чанки не считаются | Дёшево | Домашнее поселение «замерзает» или считается упрощённо; оба режима надо согласовать |
| Домашнее поселение | 1. Остаётся в полной симуляции | Честно, без особых режимов | Дороже, пока нет игрока рядом |
| | 2. Переходит на стратегический слой (час за шаг), при возврате «догоняет» | Дёшево | Нужны правила, что успевает построиться и сколько работы сделано |
| Активные чанки | Зона героя уходит с героем; при прибытии активируются чанки места назначения | Следует правилу «герой, свой город, атакуемый чужой» | При прерывании в пути нужна точка остановки на графе |
| Прерывание | Набег на дом; засада из логова по RNG «события»; гибель спутника; тревога у цели | Содержательные решения | Каждое — правило и тест |
| Стоимость | `тики = ceil(длина × стоимость_участков / скорость_отряда)`; скорость — по слабейшему | Просто, целые числа | Нужны числа скоростей в данных |
| | Дополнительно: плата едой или золотом | Цена расстояния выше | Лишняя нагрузка на экономику |

## Рекомендация

Для M5 проще всего A (переход = обычное время со скоростью ×4, отряд — `Party` с тиком прибытия) плюс вариант 1 по дому (дом живёт полностью). Если реальная длительность окажется велика, переход на B. Это предложение, не решение. Точка остановки при прерывании выбирается по доле пройденного пути, целыми числами. Сохранение во время перехода хранит цель, тик старта и тик прибытия; прибытие не должно зависеть от скорости отрисовки.

Тесты: реплей с переходом и прерыванием набегом даёт одинаковый хэш; сохранение посреди перехода и загрузка дают то же прибытие; переход в неразведанное запрещён. Пока не решаем: A10 (что хранит стратегический слой), A11 (герой в штурме), цены и скорости (данные), «порталы» (v2).

## Когда понадобится

**M5**. К **M4** нужно лишь, чтобы `Party` и тики прибытия были в модели (ADR 0013), потому что набег на лагерь орков идёт пешком или переходом.
