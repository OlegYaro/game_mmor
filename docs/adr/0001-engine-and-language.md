# 0001. Движок и язык

Статус: предложено
Дата: 2026-10-14
Требования: NFR-01, NFR-02, NFR-05, NFR-09; §17 GDD

## Контекст

GDD рекомендует Godot 4 + C# и чистое ядро на C#. Владелец делегировал выбор стека («как лучше»). MVP должен работать на macOS (машина разработки, Apple Silicon) и Windows (принятое предложение P-04). Нужна детерминированная симуляция сотен агентов, тесты без редактора и экспорт одной командой. Подробности и источники: `docs/research/godot-dotnet.md`.

Факты на 14.10.2026:
- Последняя стабильная Godot — 4.7.2 от 18.08.2026. Ветка 4.8 в разработке и требует .NET 10.
- LTS-веток у Godot 4.x нет, поддерживаются две последние минорные версии.
- Актуальный LTS .NET — 10, поддержка до ноября 2028. У .NET 8 и 9 поддержка заканчивается 10.11.2026.
- Godot 4.7 генерирует проекты под `net8.0`, но работает и с `net10.0`.
- Экспорт C#-проектов поддержан для Windows, macOS и Linux. Web не поддержан, мобильные платформы экспериментальные.
- NativeAOT и trimming для Godot C# не поддержаны.

## Варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Godot 4.7.2 .NET + C# на .NET 10 | Стабильная версия; LTS .NET; C# 14; прямой путь на 4.8 | `net10.0` в Godot 4.7 подтверждён кодом и NuGet, а не текстом документации |
| Godot 4.7.2 .NET + .NET 8 | Ровно то, что генерирует Godot 4.7 | .NET 8 выходит из поддержки через месяц |
| Godot 4.8 dev | Новейшие возможности | Не стабильна |
| TypeScript + PixiJS | Браузер, простой показ | Слабее производительность и инструменты; отклонено и в GDD |

## Решение

- Движок: **Godot 4.7.2 stable, сборка .NET** (universal для macOS).
- Язык и рантайм: **C# на .NET 10 SDK**, `TargetFramework` = `net10.0` во всех проектах, nullable включён.
- Переход на Godot 4.8: после выхода 4.8.1 отдельным коммитом, после зелёных тестов и smoke-теста.
- Установка без прав администратора: Godot из официального zip в `~/Applications`, .NET через официальный `dotnet-install.sh` в `~/.dotnet`.
- Подпись macOS-сборки в MVP: ad-hoc, без нотаризации.

## Последствия

- Core и тесты не зависят от Godot и работают на любом .NET 10.
- Если `net10.0` в Godot 4.7 проявит проблему, запасной вариант — `net8.0` только для `Game`; Core останется на `net10.0` при условии совместимости, иначе тоже `net8.0`.
- Открытая проблема Godot #124317: встроенная подпись macOS может давать невалидную подпись. Если сборка не запустится, обход — повторная подпись `codesign` в скрипте экспорта.
- На машинах с проблемным IPv6 восстановление NuGet лечится переменной `DOTNET_SYSTEM_NET_DISABLEIPV6=1`.
- Web-версии игры не будет, пока Godot не поддержит C# в web.
